# 🌿 Nuestra misión

En Book Wellness creemos que leer va mucho más allá de terminar un libro.

La lectura puede convertirse en una herramienta para reducir el estrés, estimular la imaginación, fortalecer la memoria, desarrollar la empatía y mejorar el bienestar emocional.

Nuestro objetivo es crear una plataforma donde la tecnología y la inteligencia artificial acompañen al lector en ese proceso, ayudándolo a construir hábitos saludables y una relación más significativa con la lectura.

Book Wellness no busca únicamente registrar libros: busca cuidar al lector.

---

# 📖 ¿Qué es Book Wellness?

Book Wellness es una aplicación web desarrollada con Python y Flask que funciona como una biblioteca personal inteligente enfocada en el bienestar.

Permite registrar y organizar lecturas, establecer objetivos, crear rutinas, realizar seguimiento de hábitos, registrar estados de ánimo, consultar estadísticas y recibir recomendaciones personalizadas mediante inteligencia artificial.

Todo ello con un mismo propósito:

> Promover el bienestar integral de las personas mediante el hábito de la lectura.

## 😊 Bienestar del lector

Uno de los pilares de Book Wellness es relacionar el hábito de lectura con el bienestar del usuario.

La plataforma incorpora herramientas para fomentar una experiencia de lectura más consciente y personalizada.

Incluye:

- 😊 Registro del estado de ánimo.
- ❤️ Relación entre emociones y lecturas.
- 🌿 Seguimiento de hábitos.
- 🔥 Rachas de lectura.
- 📊 Seguimiento del progreso personal.
- 🤖 Recomendaciones relacionadas con el estado de ánimo.

---

## 🎯 Productividad y objetivos

- Objetivos de lectura.
- Seguimiento de metas.
- Generación de rutinas de lectura.
- Calendario de planificación.
- Recordatorios y notificaciones.
- Seguimiento del progreso de los objetivos.

---

## 🔔 Notificaciones

Book Wellness cuenta con un sistema de notificaciones activo para acompañar al usuario durante su experiencia en la plataforma.

Las notificaciones pueden utilizarse para recordar actividades relacionadas con la lectura y los objetivos del usuario.

El usuario también puede gestionar el estado de sus notificaciones desde la aplicación.

---

## 🏆 Logros y niveles

La plataforma cuenta con un sistema de logros y progreso del lector.

Los logros se obtienen a partir de diferentes actividades realizadas dentro de la aplicación, como la lectura, el progreso y la interacción con determinadas funcionalidades.

También se incorpora un sistema de niveles que permite representar el progreso del usuario como lector.

---

## 🤖 Inteligencia Artificial

Book Wellness incorpora inteligencia artificial para ofrecer una experiencia de lectura más personalizada.

El sistema puede utilizar información relacionada con:

- Géneros y preferencias.
- Libros registrados.
- Nivel del lector.
- Historial de lectura.
- Estado de ánimo.
- Preferencias del usuario.
- Información bibliográfica disponible.

La inteligencia artificial también permite generar recomendaciones de lectura adaptadas al contexto del usuario.

# 🏗 Arquitectura

El proyecto utiliza principios de Programación Orientada a Objetos (POO), organizando diferentes funcionalidades mediante clases y módulos.

Entre los principales componentes se encuentran:

- Usuario
- Libro
- Preferencias
- Seguimiento
- Estadística
- Calendario
- SeccionLectura
- Notas
- Objetivos
- Logros
- Sistema de inteligencia artificial

La aplicación se encuentra estructurada mediante diferentes módulos y rutas de Flask que permiten gestionar las funcionalidades de la plataforma.

# 🚀 Instalación local

Para ejecutar Book Wellness de manera local:

```bash
git clone https://github.com/TU-USUARIO/Book-Wellness.git
cd Book-Wellness
pip install -r requirements.txt
python app.py
```

La aplicación también se encuentra disponible mediante su versión desplegada en Render.
